# Data Classification Policy

Minimal sample policy for MVP ingest and E2E demos.

## Purpose
Classify company data so access and retention controls can be applied consistently.

## Controls
- Label data as Public, Internal, Confidential, or Restricted before sharing outside the team.
- Store Restricted data only in approved systems with encryption at rest.
- Do not commit secrets, credentials, or Restricted payloads to source control.
- Review classification when data ownership or retention requirements change.
